# 📊 PlacementPreparationTracker
An interactive and user-friendly dashboard designed to help students track and manage their placement preparation tasks across **DSA**, **Aptitude**, and **Verbal Ability**. Built with **HTML**, **CSS**, **JavaScript**, and **Chart.js**, it provides a structured way to stay organized, motivated, and consistent during preparation.


## 🌟 Features

✔ Add and categorize tasks under DSA, Aptitude, or Verbal topics  
✔ Mark tasks as completed and view progress with dynamic progress bars  
✔ Visualize task distribution using a pie chart  
✔ See random revision reminders from completed tasks  
✔ Earn badges (Bronze, Silver, Gold) based on completion count  
✔ Explore aptitude topics (Quantitative, Logical Reasoning, Verbal Ability)  
✔ Explore DSA topics (Basics, Intermediate, Advanced)  
✔ Explore core subjects like Operating Systems, DBMS, Networks, and OOPs  
✔ Calendar widget for tracking study dates  
✔ Smooth animations and gradient backgrounds for an engaging experience  

---

## 🛠 Built With

- **HTML5** – Structured markup for content and layout  
- **CSS3** – Gradient backgrounds, animations, and responsive design  
- **JavaScript** – DOM manipulation, event handling, and dynamic task management  
- **Chart.js** – Pie chart visualization for task distribution  
- Google Fonts – Poppins for clean typography  
- Icon packs (e.g., Icons8) for achievement badges
